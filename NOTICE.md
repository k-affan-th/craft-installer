# Third-party material

`gui/assets/<app>.png` are 128 px renderings of the app icons from the storytold/<app> repositories
(`assets/app-icon/`), which are licensed under Apache-2.0 OR MIT. `gui/assets/icon.png` and `icon.ico`
are composed from four of those icons.

The installer downloads release files from https://github.com/storytold/ at run time and verifies
them against each release's `SHA256SUMS.txt`. This project is not affiliated with storytold / ArtCraft.
